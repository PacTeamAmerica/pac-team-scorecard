# PAC TEAM Commercial Scorecard

Published page only. **Do not edit anything here by hand** — it is overwritten
on the next build.

`index.html`, `build_meta.json` and `snapshot-history.json` are generated in
the private repo `PacTeamAmerica/pac-team-scorecard-data` and pushed here by
its build workflow. The exports, the archive, the build chain and the gates
all live there.

To change what this page shows, change it in the data repo and let the build
publish it. Five gates run there before anything reaches this repo; a build
that fails any of them publishes nothing and leaves this page as it was.

Live at https://pacteamamerica.github.io/pac-team-scorecard/
